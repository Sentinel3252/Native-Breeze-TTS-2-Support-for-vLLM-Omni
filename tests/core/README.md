# Breeze CPU core tests

Run from the project root in a separate Python 3.12 environment:

```bash
python -m pip install -r tests/core/requirements.txt
python -m pytest tests/core -q
```

These tests execute real PyTorch depth and text models and a tiny real Mimi
codec. They check complete-frame feedback, request-local sampling, prompt
conditioning, chunk continuity, stage transport and terminal cleanup. Worker
and adapter callbacks are extracted from their source with Python's AST so
they can execute without the CUDA-only vLLM imports. This is a unit test
boundary, not a replacement vLLM runtime or a GPU integration test.

The depth oracle in `fixtures/depth_reference.json` was generated by the
official Breeze implementation under Transformers 4.57.3, with a tiny model
and random weights. It contains no pretrained model material. To regenerate
it, create a separate environment with `requirements-reference.txt`, then run:

```bash
python tests/core/generate_depth_fixture.py
python -m pytest tests/core -q
```

The 4.x suite also compares the depth logits with the live official model.
The 5.x suite compares with the same saved oracle. The official reference
tree remains unchanged.

Full-checkpoint loading, CUDA paged attention, serving cancellation and audio
intelligibility still require the [runtime validation gates](../../docs/validation.md).
